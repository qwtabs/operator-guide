# Матрица ролей и словарь терминов

## Действия целевых ролей

| Роль | Что может делать | Ограничения |
| :--- | :--- | :--- |
| **Оператор** (operator_a, operator_b) | Создавать заявки. Читать только свои заявки. Редактировать свои открытые заявки. | Не видит чужие заявки. Не может удалять заявки. Не может обходить ограничения доступа. |
| **Техник** (technician_a) | Читать только назначенные ему заявки. Переводить их в статус `in_progress` («В работу»). Завершать их (`resolved`) с обязательным комментарием. | Не может видеть неназначенные заявки. Не может удалять заявки. |

*Примечание:* Административные действия (например, назначение исполнителя менеджером) не входят в данное руководство — для этого нужно обращаться в поддержку.

## Словарь терминов

1. **Заявка** — запись в сервисе, содержащая тему, описание и вложения, созданная для решения рабочей задачи.
2. **Номер** — уникальный идентификатор заявки (например, LAB-104). Нужен для поиска конкретной записи; его нельзя заменять номером кабинета.
3. **Статус** — текущее состояние заявки в работе (`open` — открыта, `in_progress` — в работе, `resolved` — выполнена).
4. **Вложение** — файл (PDF или PNG), прикрепленный к заявке. К одной заявке можно приложить не более трех файлов.
5. **Исполнитель** — сотрудник (например, техник), которому назначена заявка для выполнения.
