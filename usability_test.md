# Протокол испытания руководства оператора

**Режим испытания:** Аналитическое испытание по модели интерфейса (на основе файла `data/operator_observations.md`).
**Ограничения:** Стенд не предоставлен, реальные действия в приложении не выполнялись. Проверялось соответствие шагов руководства описанному интерфейсу.

| Шаг / Сценарий | Ожидание по руководству | Наблюдение (сверка с моделью) | Требуемое уточнение / Исправление |
| :--- | :--- | :--- | :--- |
| **Сц. 1:** Создание заявки | Появление сообщения «Заявка LAB-104 создана» и ссылки «Открыть». | В наблюдениях есть этот текст. Совпадает. | Уточнено, что поиск осуществляется по номеру LAB-104. |
| **Сц. 2:** 4-й файл | Появление ошибки «Можно приложить не более 3 файлов», текст остается. | Ошибка описана верно. В руководстве не хватает шага, *как именно* убрать файл. | Добавлено уточнение: «Нажмите на крестик рядом с лишним файлом». |
| **Сц. 3:** Тайм-аут | Появление сообщения «Не удалось получить ответ...». | Сообщение в руководстве и наблюдениях совпадает. | Добавлено предупреждение не нажимать «Отправить» повторно до проверки списка. |
| **Сц. 4:** Работа техника | Кнопка «В работу», затем «Отметить выполненной» с комментарием. | В наблюдениях указано наличие этих кнопок. | Уточнено, что комментарий обязателен. |
| **Сц. 5:** Отказ в доступе | Текст «Нет доступа к этой заявке» и ссылка «К списку». | Полностью совпадает с наблюдениями. | Изменений не требуется. |
